# Nexhltv

Сайт сообщества Counter-Strike 2. В корневой папке находятся два файла запуска, приложение хранится в `app`, а рабочие данные — в `storage`.

## Локальный запуск

1. Установите Node.js LTS.
2. Запустите `start.bat`, чтобы открыть сайт, или `start-admin.bat`, чтобы открыть админ-панель.
3. При первом входе в админ-панель придумайте пароль длиной не менее 12 символов и введите его дважды. Пароль не генерируется программой: на компьютере хранится только его криптографический хэш в `storage\admin-auth.json`.
4. Данные сайта и заявки хранятся в `storage`. Не удаляйте эту папку, если хотите сохранить записи.

## Публикация

Для Render укажите каталог приложения `app` как Root Directory. Задайте переменную окружения `ADMIN_PASSWORD` собственным секретом длиной не менее 12 символов. Для сохранения изменений подключите Persistent Disk с Mount Path `/var/data` и задайте `DATA_DIR=/var/data`.

На размещённом сайте первичная настройка пароля через страницу запрещена; используйте только `ADMIN_PASSWORD` в настройках хостинга. Никогда не помещайте пароль в файлы приложения или архив.

## Админ-панель

В панели можно добавлять, изменять и удалять матчи, команды, игроков и лиги/турниры, а также просматривать заявки команд, менять их статус и удалять их.

Для сброса локального пароля остановите сервер и удалите только `storage\admin-auth.json`, затем создайте новый пароль при следующем входе. Остальные данные сайта при этом сохраняются.

## Разделы сайта

- Матчи: ближайшее расписание и результаты.
- Лиги и турниры: даты, статус и описание.
- Команды: матчи, победы, поражения и рейтинг.
- Игроки: матчи, рейтинг и процент побед.
- Лига: форма заявки команды.

Пока реальные данные не внесены, статистические разделы показывают пустые состояния вместо выдуманных результатов.
